Privacy Policy

Last updated: 27 October 2026

This policy describes how Quizmoka Engine (the "Application"), operated by Pasquale Garofalo, handles data. The Application is a private automation tool used only by its owner to upload quiz videos to the owner's own Quizmoka YouTube channels.

Data the Application accesses

The Application uses the YouTube API Services with the youtube.upload scope, authorised only by the channel owner. It uses this access exclusively to upload videos and their titles, descriptions and tags to the owner's own channels.

The Application does not collect, store, sell or share personal data of YouTube viewers or of any other user. It does not read comments, subscriber lists or any viewer information.

Storage of credentials

The OAuth refresh token authorised by the owner is stored only as an encrypted secret in a private GitHub repository and is used only to upload videos. It is never shared with third parties.

Revoking access

The owner can revoke the Application's access at any time from the Google security settings page: myaccount.google.com/permissions.

Third-party terms

By using the Application you agree to be bound by the YouTube Terms of Service. Data handled through YouTube API Services is also subject to the Google Privacy Policy.
